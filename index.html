⚠️ 使用上の注意事項

本マニュアルは、Codex（デスクトップ版）を使って「AI秘書システム」を作り、日々の業務整理を任せられる状態にするための手順を解説します。

基本的な考え方

最初はCodex専用フォルダの中だけで動かし、機密情報は触らせない。

  • Codexはパソコン内のファイル作成・編集ができるAIエージェントです。設定や指示を間違えると、意図しないファイル編集や上書きが起きる可能性があります。
  • 本マニュアルでは安全性を高めるため、最初はCodex専用フォルダの中だけで作業する前提にしています。
  • 重要なファイル、機密情報、APIキー、パスワード、クレジットカード情報、SSH鍵などは、Codexに読ませないでください。
  • 慣れていないうちは「フルアクセス」をオンにしないでください。AI秘書システムの作成は、専用フォルダ内だけで十分にできます。

第1章　なぜCodexでAI秘書を作るのか

CodexはOpenAIが提供しているAIエージェントです。ChatGPTのように質問へ答えるだけでなく、ファイル作成、資料作成、ブラウザ操作、アプリ操作などを進められます。このマニュアルでは、CodexをただのチャットAIではなく、日々のtodo整理・アイデア保存・日報作成・作業ログ整理を任せられる「AI秘書」の状態にします。

このマニュアルの一番大事な方針

オリジナルスキルを増やしすぎないこと。作るスキルは AI秘書（my-secretary）だけです。

todo管理・アイデア管理・日報・テンプレートなどの必要機能は、スキルを増やすのではなく、Codexで開いている作業フォルダ内のファイルとフォルダとして作られます。

スキルをいくつも作ると、初心者は「どこに何があるか」が分からなくなります。スキルは my-secretary の1つだけにして、データはすべて作業フォルダ内にまとめると、後から見返しやすい構成になります。

AI秘書にできること

  • 今日のtodoを作成・更新し、優先度（high / medium / low）で整理する
  • 思いついたアイデアや企画案を保存する
  • 1日の完了事項・残タスク・気づきを日報としてまとめる
  • todoをもとに、その日の時間割（午前・午後の動き方）を提案する

Codexの公式情報

  • 公式の導入ページ：openai.com/codex/get-started
  • デスクトップアプリ紹介：introducing-the-codex-app

ChatGPT Plus以上のプランの場合、Codexを追加課金なしで使える場合があります。料金や利用条件は変更されることがあるため、最新情報はOpenAI公式ページで確認してください。

第2章　このマニュアルを始める前に

実際の作成に入る前に、Codex専用の作業フォルダを用意し、安全寄りの設定にしておきます。

Codex専用の作業フォルダを作る

最初からデスクトップ全体・書類フォルダ全体・仕事用フォルダ全体をCodexで開かないでください。余計なファイルまで触れてしまい、事故の原因になります。

  1. デスクトップで新規フォルダを作る
  2. フォルダ名を「Codex_AI秘書」にする
  3. Codexアプリを開く
  4. 作成したフォルダをCodexで開く

最初のおすすめ設定（安全寄り）

項目推奨設定理由
権限自動レビュー危ない操作だけ確認してくれる
フルアクセスOFF最初は事故防止を優先する
サンドボックス作業フォルダ内で作業余計な場所を触らせない
実行中のスリープ防止ON作業中にPCが止まらない
作業モード日常業務向けAI副業・SNS運用・資料作成に向く
ブラウザ/コンピューター使用必要な時だけON確認画面操作が必要な時に使う

慣れていないうちは「フルアクセス」をオンにしないでください。AI秘書システムの作成は、専用フォルダ内だけで十分にできます。

第3章　AIに作ってもらう（プロンプトコピペ編）

先ほど作ったCodex専用フォルダを開いた状態で、入力欄に以下のプロンプトをそのままコピペしてください。Codexがいくつか質問してくるので、それに答えると、あなた専用のAI秘書システムが作られます。

Codexは書き込みの前に「作成・更新するファイル一覧」を提示してきます。内容を確認してから実行の許可を出してください。

このプロンプトのポイント

  • オリジナルスキルは my-secretary だけを作る
  • todo / ideas / logs / templates / vault は作業フォルダ内に作る
  • 追加のオリジナルスキルは勝手に作らない
  • 機密ファイル（.env・APIキー等）は読まない
コピペ用プロンプト 

        

        

          
このプロンプトを貼り付けると、Codexがヒアリング → 構成の確認 → 作成 → 動作確認まで、確認を取りながら順番に進めてくれます。

        

      


      
      

        
第4章　AI秘書の使い方

        
AI秘書（my-secretary）の作成が終わったら、Codexで呼び出して使います。

        
呼び出し方

        
Codexのスラッシュメニューでは /my-secretary として表示されます。文章の中で $my-secretary と書いて呼び出すこともできます（どちらでも動きます）。入力欄に「/」を打つと候補メニューに出てくるので、そこから選べばOKです。


        
使い方の例

        

          
todoを整理$my-secretary 今日やることは、請求書作成と動画構成チェックです。優先度を整理して、今日のtodoに保存して。

          
アイデア保存$my-secretary 新しい教材のアイデアを思いついた。初心者向けにCodexの安全設定だけ解説する特典を作りたい。

          
日報作成$my-secretary 今日やったことを日報にまとめて。完了したのは動画構成、残りはサムネ案の作成。

          
スケジュール提案$my-secretary 今日のtodoを見て、午前と午後の動き方を提案して。

        

      


      
      

        
第5章　フォルダの意味とやらない方がいいこと

        
作成されるフォルダの意味

        
作業データはすべてこのフォルダ内にまとまるため、後から見返しやすくなります。

        

          

            
フォルダ用途

            
              
company/secretary/todos/今日やること、優先度、残タスク

              
company/secretary/ideas/思いつき、企画案、改善案

              
company/secretary/logs/日報、作業記録、振り返り

              
company/secretary/templates/todoや日報のテンプレート

              
company/secretary/vault/重要な成果物や保管したいメモ

            
          

        


        
最初は避けた方がいいこと

        
    
          
  • 「フルアクセス」をオンにする
    • 
          
  • デスクトップ全体をCodexで開く
    • 
          
  • 仕事用フォルダ全体をいきなり開く
    • 
          
  • .env やAPIキー入りのファイルを読ませる
    • 
          
  • よく分からないMCPサーバーを追加する
    • 
          
  • AI秘書以外のオリジナルスキルを一気に増やす
    • 
        

        

          
まずはAI秘書だけで十分です。todo・アイデア・日報・スケジュール整理ができるだけでも、Codexの便利さはかなり体感できます。

        

      


      

        
おわりに

        
    
          
  1. Codex専用の作業フォルダを作る
    2. 
          
  2. 安全寄りの設定にする
    3. 
          
  3. プロンプトをCodexに貼り付ける
    4. 
          
  4. AI秘書スキル（my-secretary）を1つだけ作る
    5. 
          
  5. 必要なtodo・ideas・logs・templatesはフォルダ内に作る
    6. 
        

        
オリジナルスキルを増やしすぎると、初心者は管理が難しくなります。まずはAI秘書だけ作って、日々の作業を整理するところから始めてください。最初の一歩は「小さく・安全に」が成功のコツです。
